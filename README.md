# Soham Rakhonde

Personal portfolio website for [sohamrakhonde.com](https://sohamrakhonde.com).

## Run locally

Open `index.html` in a browser. The site is static and does not require a build step.

## Deploy

The GitHub Actions workflow in `.github/workflows/pages.yml` deploys the site to GitHub Pages whenever changes are pushed to `main`.

In the repository's **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**.

To use a custom domain, register it with a domain registrar, then add it under **Settings → Pages → Custom domain** and configure the DNS records shown by GitHub.
